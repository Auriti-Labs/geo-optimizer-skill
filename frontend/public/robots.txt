# robots.txt for geoready.dev
#
# Why the named crawlers repeat the exclusions
# RFC 9309: a crawler obeys only the group that names it most specifically and
# ignores the "*" group. A named group that contained only "Allow: /" therefore let
# those crawlers fetch /api/, /health, /badge and /report/ even though the "*"
# group excludes them. The same rules now appear in the named group and in "*".
#
# Policy is unchanged: every crawler listed here is allowed on the public site.
# /report/demo stays crawlable on purpose (it is the public demo report).
# /api/public/benchmark and /api/stats stay readable: pages fetch them with a GET on
# load (state-of-geo, StatsBar) and the Dataset JSON-LD on /state-of-geo/ points its
# contentUrl at the benchmark. /api/stats answers with X-Robots-Tag: noindex, which a
# crawler can only see if robots.txt lets it fetch the URL.
# Rule order: specific rules first, "Allow: /" last, so parsers that stop at the
# first match behave like parsers that use the longest match.
